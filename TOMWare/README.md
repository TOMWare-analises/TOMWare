# Pintool sources

This folder is the Visual Studio project `TOMWare.vcxproj`, included from the
repository-root solution `../TOMWare.sln`. It is **not** a nested git clone.

Build: open `TOMWare.sln` at the repository root → **TOMWare** | Release | x64.
A local rebuild is **not** the campaign DLL `4BBC6270` (root README, section
**Reproduce**). Do not change `SkewMask.cpp` unless you accept invalidating
the N=30 timing table.
